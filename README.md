# 知知 · 全网口碑护肤查询助手

一个**纯静态（HTML / CSS / JavaScript）**的护肤产品口碑查询网站。用户可以像聊天一样提问，网站会从内置的**真实产品数据库**中匹配产品，并展示真实图片、使用肤感、用户自述的优缺点以及来源笔记链接——**只呈现真实数据，不编造用户原话**。

> 🤖 页面由一个温柔的 AI 助手「知知」承载，帮助你在庞杂的护肤信息里快速还原一款产品的真实体验。

---

## ✨ 功能一览

### 1. 对话式查询
- 在对话框直接输入产品名或需求，知知会**模糊匹配**产品并返回一张「产品小档案」。
- 展示内容：真实产品图、质地 / 香味 / 吸收 / 黏腻 / 搓泥等真实肤感标签、用户自述的优点与缺点、真实评论样本、以及来源笔记链接。
- 数据缺失的部分如实标注，**不伪造**真实用户评价。

### 2. 全部品类浏览
- 页面下方「全部品类」区展示全部产品卡片（含真实产品图）。
- 品类标签由数据库的真实二级分类自动生成，点击即可查看该品类全部产品。
- 每张卡片支持两个操作：
  - ❤️ **不喜欢**（右上角心碎图标）——全局隐藏该产品，之后不再展示。
  - ⭐ **收藏**（右下角星标）——加入收藏夹，便于回看。

### 3. 购买需求匹配
- 打开「购买需求」面板，可按**预算区间**、**肤质**、**产品类型**筛选，并可补充自由描述。
- 系统按「品类 > 肤质 > 预算 > 关键词」加权评分，给出 **Top 6 匹配产品**。
- 点击结果可在**页内**查看产品详情页（非弹窗）。

### 4. 想做的比较
- 在搜索框输入关键词 → 列出**全部匹配产品**作为候选卡。
- **最多选择 2 款**产品，底部悬浮托盘实时显示已选，选满 2 款后「开始对比」生效。
- 生成 2 列对比表格；支持**历史对比记录**（本地保存，最多 8 条）与**热门品类快捷入口**。
- 超出 2 款时提示「最多选 2 个，先去掉一个吧」。

### 5. 我的收藏（右上角）
- 对话框右上角按钮带**数量徽标**，点击进入独立管理页。
- 「收藏的 / 不喜欢的」两个标签页，**各带产品分类筛选栏**。
- 可在此**取消收藏 / 取消不喜欢**（取消不喜欢的商品会重新回到全部品类列表）。

## 🗂️ 项目结构

```
.
├── index.html        # 页面结构与视图容器
├── style.css         # 全部样式（配色：浅粉底 #FDF1EF，主色 #8B3A52）
├── app.js            # 全部交互逻辑（查询、匹配、收藏、对比……）
├── products.js       # 由数据脚本生成：window.PRODUCTS（158 款产品）
├── build_data.py     # 由原始数据库构建 products.js 与 images/ 的脚本
├── images/           # 按产品 ID 分目录的真实产品图
├── avatar.jpg        # 知知头像
└── user.jpg          # 用户头像
```

> ℹ️ `products.js` 与 `images/` 由 `build_data.py` 从原始数据库导出。仓库内已包含生成后的成品，可直接运行。

## 🚀 本地运行

本项目是**纯静态站点**，不需要任何后端。任选一种方式：

**方式一：Python 内置服务器**
```bash
python3 -m http.server 3030 --bind 0.0.0.0 --directory .
```
然后浏览器打开 <http://127.0.0.1:3030/>

**方式二：Node.js**
```bash
npx serve .
```

**方式三：直接双击 `index.html`**
> 建议使用前两种方式，避免个别浏览器对本地文件的跨域限制。

## 🔧 重新生成数据（可选）

如果你更新了原始护肤数据库，可重新生成 `products.js` 与 `images/`：

```bash
pip install -r requirements.txt
python3 build_data.py
```

`build_data.py` 会读取原始数据库（SQLite / CSV / JSONL / 图片），输出前端所需的 `window.PRODUCTS` 数据与分目录图片。

## 🛠️ 技术栈

- **纯前端**：原生 HTML + CSS + JavaScript（无框架、无构建步骤）
- **数据**：静态 `products.js`（由 Python 脚本从数据库导出）
- **持久化**：浏览器 `localStorage`（收藏、不喜欢、对比历史）
- **数据处理（可选）**：Python 3
